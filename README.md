# Striver A2Z DSA Sheet - Interactive Practice & Solutions

[![Live Demo](https://img.shields.io/badge/Live_Demo-GitHub_Pages-2ea44f?style=for-the-badge&logo=github)](https://avinash893.github.io/dsa-scraper/)

🔗 **Direct Live Link:** [https://avinash893.github.io/dsa-scraper/](https://avinash893.github.io/dsa-scraper/)

An interactive web application and automated scraper for [Striver's A2Z DSA Sheet](https://takeuforward.org/dsa/strivers-a2z-sheet-learn-dsa-a-to-z). Features a complete catalog of 474 coding questions, multi-language solutions (C++, Java, Python, JavaScript), practice question randomizer, progress tracking, and code exporting.

---

## 🚀 Features

- **🌐 Instant Web Practice**: Open and practice directly on [GitHub Pages](https://avinash893.github.io/dsa-scraper/) without installing anything.
- **🎲 Practice Random Question**: Click to roll a random question from Striver's sheet, prioritizing unsolved problems.
- **✅ Solved Problem Tracker**: Mark problems as solved directly from the problem list or viewer; progress is persisted automatically in `localStorage`.
- **💻 Multi-Language Code Viewer**: Browse approaches (Brute Force, Better, Optimal) with code solutions available in C++, Java, Python, and JavaScript.
- **📦 Local ZIP & PDF Exporter**: Export all solutions structured into directories by category, or compile a single C++ solutions reference manual.
- **🔍 Quick Search & Filter**: Instant filtering across all 18 topics, subcategories, problem titles, and difficulty ratings.

## 🏃 Running Locally

```bash
# 1. Clone repository
git clone https://github.com/avinash893/dsa-scraper.git
cd dsa-scraper

# 2. Install dependencies
npm install

# 3. Start local server
npm start
```

Open `http://localhost:3005` in your browser.
